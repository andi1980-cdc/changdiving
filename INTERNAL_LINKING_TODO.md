## 📝 Implementation Notes

### How to Add Links:
1. Read the target file to find the exact location
2. Use `search_replace` with sufficient context (5-10 lines before/after)
3. Add the `<p class="note">` block with proper indentation
4. Format with Prettier: `npx prettier --write <file>`
5. Check for linter errors: `read_lints`

### Common Issues:
- ⚠️ Watch for slight text variations between languages
- ⚠️ Use fuzzy match results if exact string not found
- ⚠️ Always read file first if search_replace fails
- ⚠️ Maintain consistent indentation (2 spaces)
