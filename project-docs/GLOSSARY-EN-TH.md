# Glossary English → Thai

**Role:** `living`  
**File:** `GLOSSARY-EN-TH.md`

Central EN→TH terminology for changdiving.com (technical/cave diving plus site copy terms in §18).

**How to use:** When translating or editing Thai HTML/content, **prefer these term pairs** and definitions. If a term is missing, **do not invent** a new Thai technical coinage without review—keep the English term in parentheses and add an entry in a follow-up.

**Scope:** Technical diving, cave, equipment, gas, decompression, CCR, instruction (as tabulated). **§4a** expands **Sidemount (ถังข้าง)** for manual/phrase-level Thai. **§18** covers changdiving.com–specific names and recurring translation/copy pitfalls (brands, Koh Chang, wrecks). Not a full recreational-only list.

**Source note:** Pro glossary compiled for EN/TH professional alignment (internal).

## 1. พื้นฐานการดำน้ำเทคนิค

| English | ศัพท์ไทย | คำอธิบาย |
|--------|--------|--------|
| Technical Diving | ดำน้ำเทคนิค | การดำน้ำที่ใช้อุปกรณ์ เทคนิค หรือแผนก๊าซเกินขอบเขตของการดำน้ำนันทนาการ เช่น การดำลึกเกิน 40 เมตร หรือดำในสภาพปิดเหนือศีรษะ |
| SCUBA | สกูบา | การดำน้ำแบบพกอุปกรณ์หายใจ (ถังก๊าซ เร็กกูเลเตอร์) อิสระจากผิวน้ำ; ในข้อความไทยใช้ทับศัพท์ *สกูบา* แทนการออกเสียง/สะกด *SCUBA* ยาว ๆ |
| Overhead Environment | สภาพแวดล้อมปิดเหนือศีรษะ | สภาพแวดล้อมที่ไม่สามารถขึ้นสู่ผิวน้ำได้โดยตรง เช่น ถ้ำ เหมืองร้าง หรือซากเรือที่ต้องลอดผ่าน |
| Open Water (OW) | น้ำเปิด | สภาพแวดล้อมที่สามารถขึ้นสู่ผิวน้ำได้โดยตรงตลอดเวลา ไม่มีสิ่งกีดขวางเหนือศีรษะ |
| Cave Diving | ดำน้ำถ้ำ | การดำน้ำในระบบถ้ำที่มีเพดานหินปิดเหนือศีรษะ ต้องวางเส้นนำทางและใช้อุปกรณ์เทคนิคครบชุด |
| Mine Diving | ดำน้ำเหมือง | การดำน้ำในอุโมงค์หรือเหมืองร้างที่ถูกน้ำท่วม มีสภาพปิดเหนือศีรษะและอาจมีตะกอนสูง |
| Cavern Diving | ดำน้ำคาเวิร์น | การดำน้ำในบริเวณปากถ้ำที่ยังมองเห็นแสงธรรมชาติและทางออกได้ตลอดเวลา ไม่จำเป็นต้องวางเส้น |
| Cavern Zone | เขตแสงธรรมชาติ | บริเวณในปากถ้ำที่แสงแดดยังส่องถึง มักจำกัดที่ระยะแนวนอนไม่เกิน 60 เมตรจากทางเข้า |
| Dive Plan | แผนดำน้ำ | เอกสารหรือข้อตกลงที่ระบุความลึก เวลา ก๊าซ เส้นทาง จุดหยุดดีโค และขั้นตอนฉุกเฉินสำหรับไดฟ์นั้น ๆ |
| Dive Profile | โปรไฟล์ดำน้ำ | กราฟหรือแผนภาพแสดงความสัมพันธ์ระหว่างความลึกและเวลาตลอดไดฟ์ |
| Bottom Time (BT) | เวลาใต้น้ำ | ระยะเวลาที่ใช้ในช่วงความลึกหลักของไดฟ์ ก่อนเริ่มขึ้นและหยุดดีโค |
| Run Time (RT) | เวลารวมไดฟ์ | เวลาทั้งหมดนับตั้งแต่เริ่มลงน้ำจนกระทั่งขึ้นถึงผิวน้ำ รวมทุกจุดหยุดดีโค |
| Maximum Depth | ความลึกสูงสุด | จุดที่ลึกที่สุดที่นักดำน้ำแตะถึงในไดฟ์นั้น กำหนดค่า MOD และภาระดีโค |
| Average Depth | ความลึกเฉลี่ย | ค่าเฉลี่ยความลึกตลอดไดฟ์ ใช้ประเมินปริมาณก๊าซที่ใช้และภาระดีโคโดยรวม |
| Gas Switch | เปลี่ยนก๊าซ | ขั้นตอนการสลับจากก๊าซหนึ่งไปยังอีกก๊าซหนึ่งตามความลึกที่กำหนดในแผน เช่น เปลี่ยนจาก Trimix เป็น Nitrox เมื่อขึ้นมาถึงจุดดีโค |
| Turn Pressure / Turn Point | จุดกลับ | ความดันก๊าซหรือตำแหน่งที่นักดำน้ำต้องเริ่มเดินทางกลับ ช่วยให้ก๊าซสำรองเพียงพอสำหรับออก |

## 2. อุปกรณ์หลัก

| English | ศัพท์ไทย | คำอธิบาย |
|--------|--------|--------|
| Cylinder / Tank | ถังดำน้ำ | ภาชนะแรงดันสูงสำหรับบรรจุก๊าซหายใจ มีหลายขนาดและวัสดุให้เลือกตามความต้องการ |
| Steel Tank | ถังเหล็ก | ถังที่มีน้ำหนักมากกว่าและมักจมน้ำดีกว่า ทำให้ต้องใช้น้ำหนักถ่วงน้อยลง การลอยตัวเปลี่ยนแปลงน้อยกว่าเมื่อก๊าซลดลง |
| Aluminum Tank (AL) | ถังอะลูมิเนียม | ถังที่เบากว่าบนบก แต่เมื่อก๊าซลดลงในช่วงท้ายไดฟ์จะลอยตัวมากขึ้นอย่างเห็นได้ชัด |
| Valve | วาล์วถัง | อุปกรณ์ที่คอถังสำหรับเปิด-ปิดการไหลของก๊าซ มีทั้งแบบ DIN และ Yoke |
| Backplate | แผ่นหลัง | แผ่นโลหะหรือพลาสติกแข็งที่ใช้ยึดฮาร์เนสและถุงลม เป็นโครงสร้างหลักของชุด BP/W |
| Harness | ฮาร์เนส | ระบบสายรัดที่ยึดแผ่นหลัง ถุงลม และถังเข้ากับลำตัวนักดำน้ำ |
| Wing / BCD / BC | ถุงลม | อุปกรณ์ควบคุมการลอยตัว สูบหรือปล่อยอากาศเพื่อปรับระดับลอยตัวในน้ำ |
| D-ring | ดีริง | ห่วงโลหะรูปตัว D สำหรับคลิปหรือแขวนอุปกรณ์ต่าง ๆ เช่น ไฟ รีล หรือถุงลมฉุกเฉิน |
| Bolt Snap | คลิปโบลต์สแนป | คลิปสปริงที่ออกแบบมาให้เปิด-ปิดด้วยมือเดียว ใช้เกี่ยวอุปกรณ์กับดีริงอย่างรวดเร็วและมั่นคง |
| Bungee / Shock Cord | บันจี้ | ยางยืดสำหรับรัดหรือจัดตำแหน่งถังหรืออุปกรณ์ให้แนบตัวและไม่เกะกะ |
| Slate | กระดานใต้น้ำ | แผ่นพลาสติกขาวหรือวัสดุที่เขียนได้ ใช้บันทึกแผนดำน้ำ สื่อสาร หรือจดข้อมูลใต้น้ำ |
| Wrist Slate | กระดานข้อมือ | กระดานบันทึกขนาดเล็กที่ผูกติดข้อมือ สะดวกสำหรับจดแผนหรือค่าก๊าซระหว่างดำ |
| Drysuit | ชุดดรายสูท | ชุดกันน้ำที่ปิดสนิท อากาศหรืออาร์กอนอยู่ภายในเพื่อป้องกันความเย็นและควบคุมการลอยตัว |
| Wetsuit | ชุดเวทสูท | ชุดนีโอพรีนที่ยอมให้น้ำซึมเข้าได้บ้าง ร่างกายอุ่นน้ำนั้นและใช้เป็นฉนวนความร้อน |

## 3. ชุดเร็กกูเลเตอร์

| English | ศัพท์ไทย | คำอธิบาย |
|--------|--------|--------|
| Regulator | ชุดเร็กกูเลเตอร์ | ระบบอุปกรณ์ที่ลดแรงดันก๊าซจากถังและจ่ายให้นักดำน้ำหายใจได้ในแรงดันที่เหมาะสม |
| First Stage | ชุดลดแรงดันขั้นต้น | ส่วนที่ต่อกับวาล์วถัง ทำหน้าที่ลดแรงดันสูงจากถังลงเป็นแรงดันกลางสำหรับใช้งาน |
| Second Stage | หัวจ่ายก๊าซ | ส่วนที่นักดำน้ำคาบ จ่ายก๊าซในแรงดันใกล้เคียงกับความดันรอบตัวในขณะหายใจ |
| Primary Regulator | เร็กหลัก | หัวจ่ายก๊าซตัวหลักที่ใช้หายใจปกติตลอดไดฟ์ มักต่อกับสายยาวในการดำน้ำเทคนิค |
| Backup Regulator | เร็กสำรอง | หัวจ่ายก๊าซสำรองที่ใช้เมื่อเร็กหลักขัดข้อง หรือบริจาคให้เพื่อนในสถานการณ์ฉุกเฉิน |
| Octopus | อ็อกโต้พัส | เร็กสำรองส่วนใหญ่สีเหลืองสด ใช้แบ่งก๊าซให้เพื่อนดำน้ำในกรณีฉุกเฉิน (พบบ่อยในการดำน้ำนันทนาการ) |
| SPG (Submersible Pressure Gauge) | เกจวัดแรงดันถัง | เกจแสดงความดันก๊าซคงเหลือในถัง ต้องตรวจสอบอย่างสม่ำเสมอระหว่างดำน้ำ |
| HP Port | ช่องแรงดันสูง | ช่องต่อบนเฟิร์สสเตจสำหรับต่อเกจแรงดันหรืออุปกรณ์ส่งข้อมูลความดัน |
| LP Port | ช่องแรงดันต่ำ | ช่องต่อสำหรับหัวจ่ายก๊าซ สายเติมลมถุงลม และอุปกรณ์ที่ใช้แรงดันกลาง |
| Long Hose | สายยาว | สายเชื่อมต่อเร็กหลักที่มีความยาวพิเศษ (มักยาว 1.5–2.1 เมตร) ออกแบบมาสำหรับแบ่งก๊าซในสภาพปิดเหนือศีรษะ |
| DIN Connection | ข้อต่อ DIN | ระบบต่อเร็กแบบเกลียวขัน ยึดแน่นและทนแรงดันสูงได้ดี เหมาะกับการดำน้ำเทคนิค |
| Yoke Connection | ข้อต่อโยค (A-clamp) | ระบบต่อเร็กแบบหนีบ ใช้กันแพร่หลายในการดำน้ำนันทนาการ แต่ทนแรงดันได้น้อยกว่า DIN |
| Intermediate Pressure (IP) | แรงดันกลาง | แรงดันก๊าซหลังผ่านเฟิร์สสเตจ โดยทั่วไปอยู่ที่ 8–10 บาร์เหนือแรงดันรอบตัว ใช้จ่ายไปยังหัวจ่ายก๊าซและถุงลม |
| Purge Button | ปุ่มเพิร์จ | ปุ่มบนหัวจ่ายก๊าซสำหรับกดให้ก๊าซไหลออกต่อเนื่อง ใช้ไล่น้ำออกจากหัวจ่ายหรือเช็คการทำงาน |
| Freeflow | ฟรีโฟลว์ (เรกูเลเตอร์) | ก๊าซไหลออกหัวจ่ายค้างโดยไม่ตั้งใจหายใจ มักเกิดจากฝาแตก/แผ่นยางเสีย/ตัน—แก้หรือสลับไป **เร็กสำรอง**; อ้างอิงในข้อสอบ/ทฤษฎี |

## 4. การจัดชุด (ถังหลัง / ถังข้าง)

| English | ศัพท์ไทย | คำอธิบาย |
|--------|--------|--------|
| Backmount | ถังหลัง | การจัดชุดแบบมีถังอยู่ด้านหลังลำตัว เป็นรูปแบบมาตรฐานสำหรับการดำน้ำเทคนิคทั่วไป |
| Doubles / Twinset | ถังคู่ | ถังสองใบที่ยึดเข้าด้วยกัน เพิ่มปริมาณก๊าซและสร้างระบบสำรองซ้ำซ้อน (redundancy) |
| Manifold | แมนิโฟลด์ | ชุดวาล์วและท่อที่เชื่อมถังคู่ให้ก๊าซไหลถึงกันได้ มีวาล์วแยกกลางสำหรับแยกระบบเมื่อเกิดปัญหา |
| Isolator | วาล์วแยกกลาง | วาล์วตรงกลางแมนิโฟลด์ เปิดปกติและปิดเมื่อต้องแยกถังซ้าย-ขวาออกจากกัน (เช่น เมื่อเร็กรั่ว) |
| Sidemount | ถังข้าง | การจัดชุดที่ถังอยู่ที่ด้านข้างลำตัว ช่วยให้ลอดช่องแคบได้ดีกว่า เข้าถึงวาล์วได้โดยตรง และลดแรงกดบนหลัง |
| No Mount | ถือถังผ่านช่อง | เทคนิคถอดถังออกจากชุดแล้วถือหรือดันผ่านช่องที่แคบมาก ๆ ก่อนสวมกลับ |
| Butt Plate | เพลตท้ายถัง | แผ่นยึดหรือจุดคลิปที่ก้นถังข้าง ช่วยจัดทิศทางและมุมของถังให้เรียบร้อย |
| Top Clip / Bottom Clip | คลิปบน / คลิปล่าง | จุดยึดถังข้างสองจุด คลิปบนยึดกับบ่าหรือหัวถัง คลิปล่างยึดกับเพลตท้ายหรือสะโพก |
| Trim (Tank Trim) | การจัดทรงถัง | มุมและตำแหน่งของถังในน้ำ ถังที่จัดทรงดีควรขนานกับลำตัว ไม่ห้อยหรือกางออก |
| Bands | แบนด์รัดถัง | แถบโลหะหรือสแตนเลสที่รัดถังคู่เข้าด้วยกันผ่านแผ่นหลัง |

## 4a. ถังข้าง (Sidemount) — ศัพท์และวลีเสริม

อ้างอิงคู่มือ/หลักสูตรถังข้าง: รายการนี้**ขยาย**แถว **Sidemount | ถังข้าง** ด้านบน ไม่แทนที่

| English / context | ศัพท์ไทย | คำอธิบาย |
|--------|--------|--------|
| Sidemount Diving (phrase) | การดำน้ำถังข้าง / การดำน้ำแบบถังข้าง | วลีเต็มในบทนำ/คู่มือ; ย่อ **ถังข้าง** ตรงกับ **Sidemount** ในตาราง §4 |
| Twin Cylinders (in SM) | ถังดำน้ำสองใบ (ระบบถังข้าง) | สำรองซ้ำซ้อน ทรงตัวแนวนอน และ**บริหารก๊าซ** ตาม **กฎสามส่วน** (สอดคล้อง §8) |
| Single-tank Sidemount (recreational) | ถังข้างใบเดียว (นันทนาการ) | มักเพิ่ม **เร็กสำรอง** ใช้**บันจี้**จัดสาย แล้วปรับ**ตะกั่วถ่วง**+**ลอยตัวกลาง** |
| Neutral Buoyancy (in copy) | ลอยตัวกลาง / สมดุลการลอยตัวกลาง | คู่กับ**ทรงตัว**; รายละเอียดท่าแนวนอน → **ทริม (ท่าแนวนอน)** ใน §11 |
| Weights / lead ballast | ตะกั่วถ่วง / น้ำหนักถ่วง | สมดุลหลังจูนอุปกรณ์ SM; ฝั่ง /th/ อาจเจอ “ตะกั่ว” หรือ “ตะกั่วถ่วง” |
| Regulator & SPG focus (SM) | สลับชุดเร็ก / มอนิเตอร์ SPG สองฝั่ง | วินัยสูงกว่า backmount—เช็กแรงดันซ้าย-ขวาแยก; ผูกกับ **S-Drill** / **ดริลวาล์ว** |
| Valve drill (SM) | ดริลวาล์ว | ฝึกเปิด-ปิด/กู้สมมติฐาน**วาล์วถัง**; ร่วม **Valves & Shut-Downs** ใน §13 |
| Gas donation (SM) | แบ่งก๊าซ (ถังข้าง) | กรณี OOA—แบ่งตาม SOP/หลักสูตร ใช้คู่ **OOA Drill** ใน §13 |
| Hose routing / tangles | จัดสายยาง / ลดการพันติด | สาย LP/น้ำหนัก/อินเฟลเตอร์—จัดเส้นทาง ลด **Entanglement** ใน §14 |
| Prolonged surface float | พักลอยผิวน้ำ (นาน) | บางชุด/ระบบ SM ลอยนอนยาวบนผิวไม่สบาย—ขึ้นกับ BCD/แผ่นยึด/ตำแหน่งถัง |

## 7. ความดันและฟิสิกส์ก๊าซ

| English | ศัพท์ไทย | คำอธิบาย |
|--------|--------|--------|
| Absolute Pressure / ATA | ความดันสัมบูรณ์ | ความดันรวมทั้งหมด ณ ความลึกนั้น รวมแรงดันบรรยากาศ (1 ATA) บวกแรงดันน้ำ (0.1 ATA ต่อเมตร) |
| Ambient Pressure | ความดันรอบตัว | ความดันทั้งหมดที่กดรอบตัวนักดำน้ำ ณ ตำแหน่งนั้น ๆ เท่ากับ Absolute Pressure |
| Partial Pressure (PP) | ความดันย่อย | ส่วนของความดันที่มาจากก๊าซแต่ละชนิดในก๊าซผสม คำนวณจาก PP = F × P_total |
| PPO₂ / PO₂ | ความดันย่อยออกซิเจน | ค่าบ่งบอกความเข้มข้นของ O₂ ที่ร่างกายรับจริง กำหนด MOD และความปลอดภัยจากพิษออกซิเจน |
| MOD (Maximum Operating Depth) | ความลึกใช้งานสูงสุด | ความลึกมากที่สุดที่สามารถใช้ก๊าซนั้นได้อย่างปลอดภัย คำนวณจาก PPO₂ สูงสุดที่ยอมรับได้ |
| EAD (Equivalent Air Depth) | ความลึกเทียบอากาศ | ความลึกของอากาศที่ให้ภาระไนโตรเจนเท่ากับไนทร็อกซ์ที่ความลึกนั้น ใช้วางแผนดีโคด้วยตารางอากาศ |
| END (Equivalent Narcotic Depth) | ความลึกเทียบฤทธิ์มึน | ความลึกของอากาศที่ให้อาการมึนเท่ากับก๊าซผสมที่ใช้ ช่วยประเมินผลกระทบจาก narcosis |
| Bar | บาร์ | หน่วยความดันที่นิยมใช้ในยุโรปและวงการดำน้ำ 1 บาร์ ≈ 1 ATA ≈ 14.5 psi |
| psi | พีเอสไอ | หน่วยความดันแบบอิมพีเรียล (Pounds per Square Inch) นิยมใช้ในอเมริกา 1 psi ≈ 0.069 บาร์ |
| Boyle’s Law | กฎบอยล์ | ที่อุณหภูมิคงที่ ปริมาตรก๊าซแปรผกผันกับความดัน (P₁V₁ = P₂V₂) อธิบายการเปลี่ยนแปลงปริมาตรตามความลึก |
| Dalton’s Law | กฎดอลตัน | ความดันรวมของก๊าซผสมเท่ากับผลรวมของความดันย่อยของก๊าซแต่ละชนิด ใช้คำนวณ PPO₂ และ PPHe |
| Henry’s Law | กฎเฮนรี | ปริมาณก๊าซที่ละลายในของเหลวแปรผันตรงกับความดันย่อยของก๊าซนั้น อธิบายการอิ่มตัวของเนื้อเยื่อ |

| Nitrogen Narcosis | อาการมึนจากไนโตรเจน | อาการมึนงง สับสน และตัดสินใจช้าที่เกิดจากความดันย่อยไนโตรเจนสูง มักเริ่มรู้สึกได้ที่ความลึก 30+ เมตร |
| Oxygen Toxicity (CNS) | พิษออกซิเจนต่อระบบประสาทส่วนกลาง | เกิดเมื่อ PPO₂ สูงเกิน (>1.6 ATA) อาการ ได้แก่ ชัก มองเห็นผิดปกติ กล้ามเนื้อกระตุก อาจเป็นอันตรายถึงชีวิตใต้น้ำ |
| Pulmonary O₂ Toxicity (UPTD/OTU) | พิษออกซิเจนต่อปอด | ผลสะสมจากรับออกซิเจนความดันสูงเป็นเวลานาน ทำให้ปอดอักเสบและสมรรถภาพลดลง วัดด้วยหน่วย OTU |
| Hypercapnia | ภาวะ CO₂ สูง | คาร์บอนไดออกไซด์สะสมในเลือดสูง เกิดจากหายใจตื้น ข้าม breathing หรือ scrubber เสื่อม ทำให้ปวดหัวและหมดสติ |
| Hypoxia | ภาวะออกซิเจนต่ำ | PPO₂ ต่ำเกิน อาจหมดสติอย่างฉับพลันโดยไม่มีอาการเตือน (shallow water blackout) เป็นอันตรายร้ายแรง |
| Hyperoxia | ภาวะออกซิเจนสูง | PPO₂ สูงเกินระดับปลอดภัย เพิ่มความเสี่ยงพิษออกซิเจนทั้งแบบ CNS และปอด |
| Barotrauma | บาดเจ็บจากความดัน | การบาดเจ็บของอวัยวะช่องอากาศในร่างกาย (หู ไซนัส ปอด) จากแรงดันที่เปลี่ยนแปลงอย่างไม่สมดุล |
| PFO (Patent Foramen Ovale) | รูผนังหัวใจปิดไม่สนิท | ช่องเปิดระหว่างห้องบนซ้าย-ขวาของหัวใจที่ไม่ปิดสนิทตั้งแต่กำเนิด อาจเพิ่มความเสี่ยง DCS บางกรณี |
| HPNS (High Pressure Nervous Syndrome) | กลุ่มอาการประสาทแรงดันสูง | อาการสั่น คลื่นไส้ และชักที่เกิดจากฮีเลียมในการดำน้ำลึกมากกว่า 150+ เมตร แตกต่างจาก narcosis |
